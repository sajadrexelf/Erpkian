# 02 — ماتریس اولویت‌بندی خدمات (`Service Prioritization Matrix`)

این سند اولویت تمام **۶۲ خدمت** تعریف‌شده در `01-service-catalog.md` را در چهار سطح (`P0`، `P1`، `P2`، `P3`) همراه با پیش‌نیازها، وابستگی‌ها، پیچیدگی و وضعیت آمادگی مستند می‌کند.

---

## خلاصه توزیع اولویت‌ها

| اولویت | مفهوم اجرایی در نقشه راه Erpkian | تعداد خدمات |
| :---: | :--- | :---: |
| **`P0`** | **هسته MVP نسخه اول** — ضروری برای ورود اسناد شرکت‌های پخش/عمده‌فروشی، کنترل مالی، انبار و گزارش‌های پایه | **۲۷** |
| **`P1`** | **تکمیل ارزش نسخه اول / اوایل پس از راه‌اندازی** — گزارش‌های تحلیلی تکمیلی، پیش‌بینی کوتاه‌مدت، اتصال کامل‌تر ERP و آماده‌سازی مالیاتی | **۲۵** |
| **`P2`** | **توسعه تخصصی میان‌مدت** — تحلیل‌های پیشرفته رفتار مشتری، نرخ ریزش، اعتبارسنجی ۱۶۹ و فایل حقوق | **۸** |
| **`P3`** | **افق بلندمدت و نیازمند مجوز/زیرساخت بیرونی** — ارسال رسمی سامانه مودیان و اظهارنامه رسمی (قفل‌شده در v1) | **۲** |
| **جمع** | — | **۶۲** |

> **راهنمای ستون مشتری هدف:** `پخش` = شرکت پخش، `عمده` = عمده‌فروشی، `تولید` = تولیدی، `خرده` = خرده‌فروشی/سوپرمارکت، `مستقل` = کاربر مستقل/حساب شخصی.
> **راهنمای وضعیت آمادگی:** `Ready` = آماده پیاده‌سازی با مدل داده فعلی؛ `Provisional-Delta` = نیازمند تایید دلتای کوچک (Migration 011) یا نمونه فایل واقعی؛ `Blocked-Legal` = متوقف به مجوز/گواهی بیرونی.
